它會做什麼？

給第一次安裝的人看的說明

保護組字中的 Enter

這個腳本只處理輸入法組字期間的 Enter，不讀取、不儲存、不傳送你的訊息。

  • 目前已在 macOS Safari 測試
  • iPhone / iPad 尚未測試
  • 支援中文、日文等輸入法
  • 完成輸入後，Enter 照常送出
